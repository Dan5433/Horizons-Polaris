# Question Qaos
### A question beckons an answer, but an answer can beckon many questions.
Jeopardy game created by High School students who participated in the 2026 Polaris hackathon event.

## About
This is a Jeopardy-themed game, where your goal is to choose one of five question prompts given by the game that best associates with a given answer. Players will explore the game environment and interact with their file system to find clues on what the most associated question prompt will be for the given answer.

## How to Download
* Go to the [releases](https://github.com/Dan5433/Horizons-Polaris/releases) tab
* Download the ZIP file for your operating system
* Unpack the ZIP
* Run the exe file

## How to Play
* You get an answer and have to match it to one of the 5 questions
* Use the laptop to navigate the clues in your file system
* Inspect the game environment to know where to look for clues in the file system
* Use the button in the bottom-left to submit your guess
