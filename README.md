# Foreward
A question beckons an answer, but an answer can beckon many questions.

Given an answer, you have to find the question that fits it using context clues found on your computer's file system, navigating it using the subtle differences in the game environment.

# Question Qaos
Jeopardy game created by High School students who participated in the 2026 Polaris hackathon event.

## About
This is a jeopardy-themed game, where your goal is to choose one of five question prompts given by the game that best associates with a given answer. Players will explore their environment to find clues on what the most associated question prompt will be for the given answer.

## How to Play
* Go to the [releases](https://github.com/Dan5433/Horizons-Polaris/releases) tab
* Download the ZIP file for your operating system
* Unpack the ZIP
* Run the exe file
